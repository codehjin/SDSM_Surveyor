# 별도 작업 — 관찰형 3종 공식 종목록(국가생물종목록) 반영

> 본 순서(01~06) 밖의 독립 작업. 필독: `90_TECH_NOTES.md`
> **입력 파일 구조는 실제 파일을 열어 검증했다(2026-08-20). 아래 열 번호를 신뢰할 것.**

---

## 1. 배경

`species.json`의 조류·포유류·양서파충류는 관리자 DB의 **과거 조사기록에서 뽑은 국명 문자열 목록**이라 품질이 낮다(조류는 학명 보유 34%, 표기 충돌 19종). 그래서 2단계에서 학명 자동 채움을 넣지 않았다.
→ 사용자가 **국가생물종목록**을 제공했다. 이 문서는 그 목록을 반영하는 작업이다.

**어류·저서동물은 건드리지 않는다.** 관리자에 별도 마스터(`FishSpeciesList` 253종 / `BenthosSpeciesList` 821종)가 있고 이미 정상이다.

## 2. 입력 파일 (확정)

`docs\_input\생물종 일괄입력.xlsx` (없으면 사용자 업로드본을 이 경로로 복사)
국립생물자원관 국가생물종목록 기반. KTSN 번호 포함.

### 2-1. 사용할 시트

| 시트 | 행수 | 용도 |
|---|---|---|
| `조류` | 617종 | → `Bird` |
| `포유류` | 125종(국명 있는 행) | → `Mammal` |
| `양서류` | 28종 | → `Amphibian` (**파충류와 병합**) |
| `파충류` | 37종 | → `Amphibian` (**양서류와 병합**) |
| `멸종위기 야생생물 목록` | 282행 | 보호종 등급 조인 |
| `천연기념물 목록` | 76행 | 천연기념물 조인 |
| `생태계교란생물 목록` | 40행 | 생태계교란생물 조인 |

> ⚠ **우리 앱의 `양서파충류`는 한 분류군인데 원본은 `양서류`·`파충류` 두 시트로 나뉜다. 반드시 합칠 것.** (28 + 37 = 65종)

**이번 범위 밖(사용하지 않음)**: `관속식물류`·`어류`·`무척추동물류`·`곤충류`·`균류`·`돌말류`·`희귀식물`·`특산식물`.
→ 향후 활용 여지만 기록: 돌말류=TDI 모듈, 관속식물류=수변식생(RVI), 어류·무척추=보호종 플래그 보강.

### 2-2. 분류군 시트의 열 구조 (조류·포유류·양서류·파충류 공통)

**헤더가 2행이다.** 행1=계층명(Phylum/Class/Order/Family/Genus/Species…), 행2=하위헤더(Name/국명).
**데이터는 행3부터.** 시트마다 총 열 수가 다르므로(조류 63, 나머지 31) **열 개수에 의존하지 말 것.**

바로 쓸 수 있는 완성형 열이 이미 있다 — **학명을 조각(Genus+Species)에서 조립할 필요가 없다.**

| 열(0-based) | 내용 | 매핑 |
|---|---|---|
| 0 | KTSN(국가생물종번호) | (선택) 고유 키로 보관하면 향후 대조에 유용 |
| **8** | Order 국명 | **`OrderKo`** (예: 닭목) |
| **10** | Family 국명 | **`FamilyKo`** (예: 꿩과) |
| **26** | **학명** (완성형) | **`SpeciesEn`** (예: `Tetrastes bonasia`) |
| **27** | **대표국명** | **`SpeciesKo`** (예: 들꿩) |
| 28 / 29 | 명명자 / 명명년도 | (선택) |

> 안전장치: 열 번호를 상수로 박되, **행1·행2 헤더 텍스트로 위치를 검증**하고 어긋나면 오류를 내라(원본 파일이 갱신될 수 있다).

### 2-3. 데이터 처리 규칙

- **대표국명(열27)이 빈 행은 건너뛴다.** (포유류에 5행 존재 — 상위 분류 행)
- **중복 국명**: 조류에 8건(`큰기러기`·`중대백로`·`크낙새`·`노랑때까치` 등, 아종 차이로 학명이 다름).
  → **첫 항목만 채택**하고, 건너뛴 항목을 콘솔에 목록으로 출력해 사용자가 확인할 수 있게 한다. 임의로 합치거나 학명을 섞지 말 것.
- 앞뒤 공백 제거만 하고 **종명 원문은 변형하지 않는다**(CLAUDE.md §7.3).

### 2-4. 보호종 조인 (별도 3개 시트)

보호종 정보는 분류군 시트에 없다. 아래 시트를 **학명(정확도 우선)으로 조인**하고, 학명이 안 맞으면 국명으로 보조 매칭한다.

| 시트 | 헤더행 | 열 | 채울 필드 |
|---|---|---|---|
| `멸종위기 야생생물 목록` | 행2 | 등급 / 분류군 / 국명 / 학명 | 등급 `Ⅰ급`→`Endangered1`, `Ⅱ급`→`Endangered2` (값 `"O"`) |
| `천연기념물 목록` | 행1 | 분류군 / 지정번호 / 지정명칭 / 지정일자 / 국명 / 학명 / 비고 | `NaturalMonument` = `"O"` |
| `생태계교란생물 목록` | 행1 | No. / 분류군 / 순번 / 국명 / 학명 / 비고 | **`Invasive` = `"O"` (신규 필드)** |

- 각 시트의 `분류군` 값으로 대상을 거른다: 조류=`조류`, 포유류=`포유류`, 양서파충류=`양서류·파충류`/`파충류`.
- 천연기념물 시트에는 국명이 빈 행(예: `고니류` 같은 상위 지정)이 있다 → 건너뛴다.

## 3. 작업

### 3-1. 공유 모델 확장
`SDSM\SDSM_Models\SpeciesCatalog.cs`
- 관찰형 3종을 `List<string>` → **`List<ObservedSpecies>`**
  ```csharp
  public class ObservedSpecies {
      public string SpeciesKo { get; set; } = "";
      public string? SpeciesEn { get; set; }
      public string? OrderKo { get; set; }
      public string? FamilyKo { get; set; }
      public string? Endangered1 { get; set; }
      public string? Endangered2 { get; set; }
      public string? NaturalMonument { get; set; }
      public string? Invasive { get; set; }   // 생태계교란생물
      public string? Ktsn { get; set; }       // 국가생물종번호(선택)
  }
  ```
- **하위 호환 필수**: 기존 `species.json`(문자열 배열)도 읽히게 한다. 역직렬화 시 문자열이면 `SpeciesKo`만 채운 객체로 변환.
  이 처리가 없으면 구형 파일을 쓰는 배포본이 **종목록을 통째로 잃는다.**

### 3-2. 로더
`Data\ISpeciesListProvider` / `SpeciesListProvider`
- `GetBirdSpecies()`·`GetMammalSpecies()`·`GetAmphibianSpecies()` 반환 타입을 `List<ObservedSpecies>`로 변경
- `Fallback()` 최소 시드도 새 타입에 맞춤

### 3-3. species.json 재생성
- 위 규칙대로 변환해 `Bird`·`Mammal`·`Amphibian` 갱신 (**어류·저서동물 부분은 그대로 보존**)
- `Version` = `nibr-YYYYMMDD`, `GeneratedAt` 기록
- 변환 결과를 콘솔에 출력: 분류군별 종수, 보호종 매칭 건수, **건너뛴 중복·빈 국명 목록**
- 변환 스크립트는 재실행 가능하게 저장소에 남긴다(원본 목록이 갱신되므로)

### 3-4. 화면 반영 (조류·포유류·양서파충류)
- 빠른추가 콤보·그리드 국명 편집기의 항목을 `ObservedSpecies`로 교체(`DisplayMemberPath="SpeciesKo"`, 초성 검색 유지)
- **종 선택 시 학명·목·과 자동 채움**(어류·저서 패턴). 단 **조사자가 덮어쓸 수 있게** 잠그지 않는다.
- `PasteRows`에서도 국명으로 조회해 학명·목·과를 채운다(미매칭이면 국명만 저장)
- 그리드에 **목·과 열 추가**(어류 패턴과 동일)
- `IsProtected` 강조에 `Endangered1/2`·`NaturalMonument` 반영. **`Invasive`는 별도 표기**(보호종과 의미가 반대이므로 같은 색으로 묶지 말 것)

### 3-5. 이상치 경고
종목록에 없는 종은 기존 규칙대로 **"과거 기록 없음 (신규 종 확인)"** 비차단 경고. 추가 작업 없음.

### 구현 메모

- `SpeciesCatalog.Bird/Mammal/Amphibian` : `List<string>` → `List<ObservedSpecies>`.
  **하위 호환**은 `ObservedSpeciesListConverter`가 담당한다(문자열이면 `SpeciesKo`만 채운 객체로 변환).
- 화면 3종 : 빠른추가 콤보·그리드 국명 편집기가 종 객체를 선택하고, 선택 시 `ApplySpecies()`로 학명·목·과를 채운다.
  **잠그지 않으므로 조사자가 그대로 덮어쓸 수 있다.** 국명을 목록에 없는 값으로 바꾸면 *자동으로 채운 값만* 비운다.
- 붙여넣기는 국명으로 조회해 채우되, **붙여넣은 셀 값이 있으면 그 값이 우선**한다.
- 보호종은 행 강조(Accent) + `구분` 열, 교란종은 **다른 색**(Validation) + `구분` 열로 분리 표기했다.
