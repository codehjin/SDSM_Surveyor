## 8. 문서와 코드 차이 (확인 거리)

1. **서식수변 조사불가 사유** — 지침 [서식 7]·양식 D14 는 `접근불가, 건천화, 공사중, 준설` 4가지인데, 앱 화면 툴팁·경고는 "서식수변의 조사불가 사유는 '접근불가' 하나뿐"이라 하고 등급 `-` 판정도 `접근불가` 가 든 글만 본다(`HabitatEvaluator.cs:38-43`). 다른 사유를 적으면 점수·등급이 그대로 나온다.
2. **[서식 7] 보조 칸 없음** — 종횡사주·유속 발생 횟수, 하천변 폭 11회 실측·비율 계산, 저질 구성비 7칸, 횡구조물 상·하류, 고도는 앱·양식 모두 없다(지침근거 §5-3 · §7 L 후보 · 미결정).
3. **조류·포유류 양식 I열 `특징`** — 양식 설명은 보호 구분(멸종1급·교란종·천연기념물 등)인데 앱은 자유 글 `특징` 을 넣고, 자동 `구분` 은 일괄입력용에 내지 않는다(보고서에만).
4. **포유류 관찰지유형 열** — 앱은 양식 머리대로 S열에 쓰지만 관리자 Import 는 R열을 읽었다(코드 주석 `MammalExcelExporter.cs:12-13` — 관리자 쪽 수정 여부 확인 필요).
5. **조류 대항목·세부항목·서식유형, 포유류 관찰지유형은 선택지 없는 자유 글** — 양식에는 번호 목록이 있다. 서식유형만 번호 1~6 → 이름 변환. 조류 U3(12개)·V3 번호 순서가 서로 달라 대항목 번호는 바꾸지 않는다(`FormChoices.cs:76`).
6. **붙여넣기 열 순서 주석과 그리드 순서** — 조류 VM 주석은 "열 순서 = 그리드 순서"라 하지만 실제 붙여넣기 순서는 `… 과 · 도래유형 · 대항목 · 세부항목 · 서식유형 · 위도 · 경도 …`이고 그리드 1행은 `… 과 · 위도 · 경도 · 특징 · 특이사항 · 구분`(분류 4칸은 2행). 매뉴얼에는 붙여넣기 순서를 따로 적어야 한다(포유류·양서도 흔적이 위도 앞).
7. **포유류 요약 단위** — 위 요약 스트립은 `… 흔적`, 아래 상태 바는 같은 값을 `… 개체` 로 쓴다(`MammalEntryControl.xaml:45,206`).
8. **흔적·관찰 2행 칸, 조류 개체수 그리드 칸에는 IntegerInput 이 없다** — 빠른추가 수량 칸(§24-3)만 정수 검사. 그리드 셀은 `int?` 형 변환에 맡겨 글자는 거부(빨간 테두리)되지만, 음수(`-3`)는 형 변환상 들어갈 수 있다(코드상 추정 · 실행 확인 안 함).
9. **붙여넣기 좌표** — 행 위도·경도 붙여넣기는 십진수만 읽고 도분초는 말없이 빈칸(양식은 도분초도 허용). 그러면 행 좌표 대체 규칙으로 지점 좌표가 나갈 수 있다.
10. **수질 날씨** — 수질·서식수변 양식 D11 은 `1 맑음, 2 흐림, 3 비(눈)` 숫자 코드인데 앱은 글자(`맑음` 등)를 그대로 쓴다(관찰형 양식은 글자 `맑음, 흐림, 비`).
11. **양서 조사일** — 양식 `0000-00-00`(날짜 서식) · 앱은 글자 `yyyyMMdd`(관리자 Import 가 8자리 글자를 날짜로 바꾼다는 주석).
12. **수질 수심** — 앱(관리자 모델)에는 있으나 2026-03 양식에 행이 없어 37행에 덧붙인다. **수질 비고**는 양식·관리자에 칸이 없어 일괄입력용에 나가지 않는다(지시서 §24-6 결정 — 다음 판 과제).
13. **비고만 있는 자료** — 수질·서식수변 모두 비고만 적으면 '자료 있음'·내보내기 조건에서 빠진다(`WaterQualityEntryViewModel.Session.cs:19` · `HabitatWaterEdgeEntryViewModel.Session.cs:21-22`). §24-7 은 "생기지 않음"으로 결정.
14. **CLAUDE.md "수질 측정 23칸(등급 9 + 추가 14)"** — 화면 `측정 항목` 9칸 중 등급이 있는 것은 8(생태독성 제외). 보고서 각주는 생태독성을 추가항목에 넣어 "15종"이라 쓴다 — 같은 23칸을 다르게 나눈 표현.
15. **서식수변 항목 이름 표기** — 화면 `9. 제외지 토지 이용`·`10. 제내지 토지 이용`(띄어 씀), 보고서 머리 `제외지 토지이용`·`제내지 토지이용`(붙여 씀, `ItemNames`), 양식 B18 `하도 정비 / 하도의 자연성` vs 화면 `2. 하도 자연성`. 선택지 설명(예 `정비X 자연사행`)은 양식 D열 판정점수의 줄임말(전문은 콤보 툴팁).
16. **서식수변 점수 선택 해제** — 콤보에 비우기 단추가 없어 한 번 고른 점수를 화면에서 미선택으로 되돌릴 수단이 코드상 보이지 않는다(도래유형 등 SingleChoiceBox 는 [비우기] 있음). 실행 확인 필요.
17. **버튼 툴팁 차이** — 서식수변·관찰형 [일괄입력용] 툴팁은 `(레거시 양식)` 이 붙고 수질은 없다.
18. **`IObservationRow` 주석** — "포유류·양서파충류는 흔적 12칸"이라 적혀 있으나 양서파충류는 6칸(코드 주석만의 차이).
19. **reference.json** — 어류 55종 · 저서 118종 범위만 있어 이 범위(관찰형 · 서식수변 · 수질)에는 쓰이지 않는다(`Data\ReferenceRangeProvider.cs:20-24`).
