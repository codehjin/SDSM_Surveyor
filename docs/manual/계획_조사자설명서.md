## 1. 기능 전수표(요약)

> 줄마다 근거는 원문 3편에 있다. 여기서는 설명서에 실을 단위로 묶었다. **굵게** = 설명서에서 꼭 경고해야 할 동작.

| 기능 | 설명 |
|---|---|

### 1-3. 종 입력 공통(어류 · 저서 · 조류 · 포유류 · 양서파충류)

| 기능 | 설명 |
|---|---|
| 빠른추가 | 초성 · 부분 검색(후보 80개까지) → 개체수 → Enter/[추가]. **목록에서 고른 종만** 들어감. 개체수 칸 = 어류 · 관찰형 정수 · 저서 소수. 같은 종은 새 행 없이 더함(칩 「… (합산)」) |
| [종목록] 창 | 국명 · 학명 · 초성 검색 · 두 번 누르면 개체수 빈칸으로 넣음 · [엑셀로 저장](`종목록_{분류군}_{판}.xlsx`) |
| 그리드 | 맨 아래 새 행에 직접 입력 · 정렬 없음(입력 순) · 우클릭 「이 행 삭제」/[행 삭제](확인 창 기본 = 취소) · [빈 행 정리] · 비고 열은 **세션에만**(엑셀에 안 나감) |
| Ctrl+V | 엑셀 여러 줄 · 어류 · 저서 = 1열 국명 · 2열 개체수 / 관찰형 = 정해진 열 순서(그리드 순서와 다름 — 부록에 표). **머리글 줄까지 붙이면 「국명」 행이 생김** |
| 목록 밖 종 | **그리드 새 행 · 붙여넣기로만.** 지우지 않고 저장 · 행 경고 「종목록에 없는 국명 — 오타인지 확인하세요」. 어류 = 길드 메트릭에서 빠지고 종수 · 개체수에는 들어감(§23) · 저서 = BMI 에서 빠짐 |
| 같은 종 | 빠른추가 · 편집 확정 때 합침. 예전 세션의 중복은 경고만 |
| 이상치 경고 | `reference.json` 어류 55 · 저서 118종의 과거 최대 초과 · 「과거 기록 없음 (신규 종 확인)」. **막지 않음.** 목록 대부분 종이 기준 밖이라 자주 뜸 |
| [출현종 없음(0종)] | 어류 · 저서 — 조사했으나 0종 → 0 · E |
| 분류군 조사일 | 비우면 조사개황 조사일 · 다르면 그 분류군 엑셀에 이 날짜(N3) |

### 1-5. 입력 칸 규칙 · 경고와 막힘

| 기능 | 설명 |
|---|---|
| 정수 칸 | 0 이상 정수 · 다른 글자는 **받지 않고 들어오기 전 값으로 되돌림** · 「정수만 넣습니다 — 소수점·글자는 받지 않습니다」(하상 % 는 「0~100 사이 정수만 넣습니다」) |
| 소수 칸 | 숫자 · 소수점 하나 · 기온만 맨 앞 '-' · 「숫자만 넣습니다 — 글자 · 쉼표는 받지 않습니다(소수점은 하나)」. 수질은 검출한계 미만 안내를 붙임 |
| 선택 칸 | 양식 선택지만. 예전 값은 「{값} (양식 외)」 + 경고 · 지우지 않음. 복수 선택 직접 입력 칸은 Enter 로 추가 |
| 조사불가 | **어류 · 저서 = 공백을 뺀 글이 '접근불가' · '건천화' · '준설' · '공사중' 과 똑같을 때만** 등급 '-'. **서식수변 = '접근불가' 가 들어 있으면** '-' |
| 경고(막지 않음) | 하상 합계 ≠ 100 · 양식 외 값 · 이상치 · 목록 밖 국명 · 같은 종 중복 · 개체수 미입력 행 · 채집기 횟수 정수 아님 |
| 막힘([일괄입력용]만) | 어류: 하천차수 빈칸 · DE~TU 정수 아님 / 저서: 소수 6칸 숫자 아님 / 수질: 23칸 숫자 아님(+ 'ND' 안내). 상태 바에 「일괄입력용을 만들지 않았습니다 — …」. 보고서용은 막지 않음 |
| 확인([일괄입력용]) | 어류 · 저서 개체수 0 · 빈칸 종 → 「내보내지 않는 종 … — 계속할까요?」 [확인]/[취소] |
| 엑셀 단추 꺼짐 | 어류 · 저서 = 개체수 > 0 행 · 0종 · 조사불가가 없으면 / 수질 = 23칸 모두 빈칸(비고만이면 꺼짐) / 서식수변 = 15칸 모두 미선택이고 조사불가시도 빈칸 |

## 5. PDF 만드는 방법과 시험 결과

### 5-1. 이 PC 에 있는 것

| 도구 | 상태 |
|---|---|
| pandoc · wkhtmltopdf · weasyprint · typst · LaTeX | 없음 |
| Python 3.14(`C:\Python314`) | 있음 — markdown-it-py 4.2.0 · pypdf 6.19.0 · pygments(사용자 site-packages) |
| Chrome 148 · Edge 156 | 있음(헤드리스 `--print-to-pdf`) |
| Pretendard | 시스템 글꼴엔 없음 → 앱 `SDSM_Surveyor_App\Assets\Fonts\Pretendard-Regular/SemiBold/Bold.ttf`(OFL)를 `@font-face` 로 |
| 쪽 사진(검토용) | Windows 내장 PDF 렌더러(Windows.Data.Pdf) PowerShell 스크립트로 PNG |

### 5-2. 방법(새로 설치할 것 없음)

1. markdown-it-py(표 켬)로 Markdown → HTML. 앞머리(`title` · `version` · `date`)로 표지.
2. `#` · `##` 에 번호 · id 를 붙이고 목차(링크 + 점선 + 쪽 번호 자리)를 만든다. 문단에 그림 하나면 `figure` + 그림 설명(alt).
3. CSS: `@page { size: A4 }` · 쪽 아래 가운데 `counter(page)`(표지는 뺌) · 장마다 새 쪽 · 표 머리줄 반복 · 행이 쪽에서 안 쪼개짐 · Pretendard.
4. Chrome(없으면 Edge) 헤드리스로 인쇄 → pypdf 로 목차 링크가 가리키는 쪽을 읽어 → 쪽 번호를 넣고 **한 번 더 인쇄**(2회).
5. `--generate-pdf-document-outline` 으로 PDF 책갈피(장 단위).

### 5-3. 시험(스크래치 `scratchpad\manual\pdftest\` · test.md 3장 · 표 2 · 그림 2)

| 확인 | 결과 |
|---|---|
| 쪽 · 시간 | 6쪽 · 1회 4~6초 · 2회 인쇄 |
| 목차 쪽 번호 | 1차 · 2차 같음(제목 8개 모두) · 목차 줄 점선 + 오른쪽 쪽 번호 |
| 쪽 번호 | 쪽 아래 가운데 · 표지 없음 · 목차 2쪽부터 |
| 글꼴 | PDF 에 Pretendard Regular · SemiBold · Bold 포함(+ 코드용 Consolas) |
| 표 | '기능 \| 설명' 2열 · 머리줄 색 · 쪽을 넘는 30행 표의 머리줄이 다음 쪽에 반복 |
| 그림 | 가운데 · 테두리 · 아래 「그림 1. …」 · 쪽에서 안 쪼개짐 |
| 책갈피 | 장(h1) 단위 생성 |
| Chrome · Edge | 둘 다 같은 결과. **Edge 156 은 PDF 를 쓰고도 프로세스가 끝나지 않음** → PDF 가 2초 동안 그대로면 프로세스를 닫게 함(Chrome 은 바로 끝남) |
| 고친 것 | 코드 글자 안 한글이 굴림체로 바뀜 → 코드 글꼴 다음 순위를 Pretendard 로(재시험 굴림체 없음) · 출력 파이프를 잡으면 Edge 자식 프로세스 때문에 끝나지 않음 → 파이프 안 씀 |
| 남은 것(S3) | 책갈피에 절(h2)도 넣을지 · 그림 강조 그리기 · 긴 표 열 너비 |

- 시험 스크립트: `scratchpad\manual\pdftest\build.py`(Markdown → PDF · 2회 인쇄) · `pdf2png.ps1`(쪽 → PNG). S3 에서 저장소 `tools\manual_pdf.py` 로 옮긴다. 관리자(A1 · A3)도 같은 스크립트(글꼴 경로만 인자).
- 새로 설치해야 했다면 후보: pandoc + wkhtmltopdf(wkhtmltopdf 개발 중단 · 한글 글꼴 설정 번거로움) · WeasyPrint(Windows 에 GTK 필요) · typst(Markdown 직접 못 읽음). 지금 방법이 되므로 쓰지 않는다.
