## 1. 바뀐 것

### 1-1. 저서 화면

- `BenthosEntryControl.xaml` — 암반·콘크리트 칸 두 개를 지웠다. 남은 6칸의 이름은 지침 [서식 2] · <표 1>을 따른다.
  칸 폭은 Sm(128) → Md(176)으로 넓혔다. 지침 이름이 길어서 '진흙 이하(<0.063mm)'·'작은돌(64~256mm)'이 두 줄로 꺾이고 칸 높이가 어긋났기 때문이다(첫 사진에서 찾음). 6칸은 여전히 한 줄에 들어간다.
- `BenthosEntryViewModel.SubstrateFields` — 6칸(화면 이름, 값)을 한 곳에 두었다. 합계(`SubstrateTotal`) · 경고(`SubstrateWarning`) · 접힌 요약줄 · 'n칸 입력됨' 이 이것을 쓴다.
  정수 경고 이름도 지침 이름이다(예: '0~100 정수가 아닌 칸: 왕모래 7.5').
- `Bedrock`·`Concrete` 속성과 세션 DTO 칸은 남겼다(읽기 호환). 값이 남아 있어도 합계·경고·내보내기에는 들어가지 않는다(시험 ①·②에서 확인).

### 1-3. 예전 세션의 저서 암반·콘크리트

- `BenthosEntryViewModel.MoveRockConcreteToNote()` — 세션을 불러올 때(`RestoreState`) 부른다.
  - 0 보다 큰 값은 특이사항 끝에 `하상 암반 10% · 콘크리트 5%(지침 저서 하상 6칸 밖 · 옮김)` 를 덧붙인다. 특이사항에 글이 있으면 ` / ` 로 잇는다. 하나만 있으면 그 하나만 적는다(예: `하상 콘크리트 5%(…)`).
  - 0 이나 빈칸이면 그냥 비운다(특이사항·안내 없음).
  - 두 칸은 비운다.
- 옮겼으면 토스트로 한 번 알린다: '저서 하상 암반·콘크리트 값을 특이사항으로 옮겼습니다(지침 저서 하상 6칸 밖) — [임시 저장]을 누르면 반영됩니다'.
- 저절로 저장하지 않는다. 옮겼으면 불러온 직후를 '저장 안 한 변경'으로 둔다(G2 · §5). 그래서 닫거나 다른 세션으로 넘어갈 때 기존 저장 확인을 묻는다.
  옮긴 것이 없으면 종전처럼 변경 없음이다. 저장하지 않고 닫았다가 다시 열면 다시 옮기고 다시 알린다. 세션 파일은 사용자가 저장할 때까지 그대로다.
- 세션 파일 형식은 그대로다. 저장하면 `"Bedrock": null`·`"Concrete": null` 로 칸은 남는다. 다시 열면 더 옮기지 않는다(특이사항이 한 번만 붙음).
- 어류 자료는 옮기지 않는다(같은 세션의 어류 암반 10·콘크리트 5 그대로 · 시험 ④⑤).
- 자료함 시드 세션(`sessions_seed\` 3개)의 저서 암반·콘크리트는 모두 `null` 이다. 그래서 시드로는 이 안내가 뜨지 않는다.

## 5. 마무리(G2) — §3 확인 사항 반영

> 지시: 2026-10-21 채팅 지시 'v0.4.1 마무리'(1 · 2 · 시험). G 의 커밋하지 않은 변경 위에 이어서 했다 — 커밋하지 않았다.

### 5-1. 옮긴 경우 불러온 직후 = 저장 안 한 변경

- `ITaxonSession.RestoreAdjusted`(기본 구현 false)를 더했다. 저서 VM 만 '마지막 불러오기에서 암반·콘크리트를 옮겼는가'를 돌려준다. `RestoreState` 시작과 `ClearData` 에서 false 로 되돌린다.
- `SessionService.LoadAsync` 는 종전처럼 `MarkClean()` 한 뒤, 옮긴 분류군이 있으면 저장 기준을 어떤 화면과도 같지 않은 값으로 둔다. 그래서 `HasUnsavedChanges()` = true 가 된다.
  닫기(`MainSurveyWindow.OnClosing`)와 다른 세션으로 넘어가기(`UnsavedChangesPrompt`)가 기존 저장 확인을 그대로 묻는다. 새 창·새 문구는 없다.
- 옮긴 것이 없으면(0·빈칸 · 예전 값 없음 · 이미 저장한 세션) 종전처럼 변경 없음이다.
- 안내는 한 번(토스트)이다. 저장하지 않고 닫았다가 다시 열면 다시 옮기고 다시 알린다(그대로 둠).
- 범위는 '세션 열기'(`LoadAsync`)만이다. [차수 복제]·복구본 불러오기는 종전 그대로다(복제는 새 세션이고, 복구본은 이미 '저장 안 함'으로 올라온다).
