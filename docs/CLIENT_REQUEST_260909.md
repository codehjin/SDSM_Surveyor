## B-3. 종목록 팝업 + 엑셀 내려받기  (≈1일)

### 무엇을
빠른추가 검색창 옆에 [종목록] 버튼. 누르면 **현재 담당 분류군의 등록 종 전체**를 목록으로 보여주고, 엑셀로 내려받을 수 있다.

### 화면
- 모달 창. 상단 검색칸(국명·학명·초성 동시 검색), 하단 그리드.
- 컬럼은 분류군별 종목록 원본 컬럼 그대로. 저서동물 예: 문 · 강 · 목 · 과 · 학명 · 국명 (+오탁치 s · 지표가중치 g가 있으면 함께).
- 행 더블클릭 → 그 종을 야장에 추가하고 팝업 닫기(개체수는 비움, 포커스는 개체수 칸).
- 우하단 [엑셀로 저장] → `종목록_저서동물_nibr-20260820.xlsx`
- 창 제목에 **종목록 버전** 표기: `종목록 (저서동물) · nibr-20260820 · 1,842종`

### 규칙
- **담당 분류군만.** 다른 분류군 종목록은 보이지 않는다(부사장 확정).
- 종목록 데이터는 `SpeciesListProvider` 가 이미 읽고 있는 것을 그대로 쓴다. 새 파일을 읽지 말 것.
- 엑셀은 기존 `Export/ExcelStyle.cs` 서식 재사용. 새 라이브러리 추가 금지.

### 맹점
1. **종목록 버전 불일치** — 조사자앱 종목록과 관리자앱 종목록이 다르면 나중에 일괄등록에서 종명이 안 맞는다. 팝업 제목에 버전을 반드시 띄우고, 엑셀 첫 시트 A1에도 버전 문자열을 쓴다.
2. **종 수가 많다** — 저서동물 1,800종대. 가상화(`EnableRowVirtualization`) 안 켜면 팝업이 멈춘다.
3. **중복 추가** — 이미 야장에 있는 종을 더블클릭하면 새 행을 만들지 말고 기존 행으로 스크롤+포커스.
4. **국명이 `-` 인 행** — 원본에 국명 없는 종이 있다. 학명으로 표시하고 `-` 로 검색되지 않게 한다.
5. 엑셀 저장 위치는 마지막 저장 폴더를 기억(`AppSettings`). 바탕화면 강제 저장 금지.

## B-2. 이전 값 고정 (압정 토글)  (≈1.5일)

### 무엇을
조사개황 6개 칸 오른쪽에 **압정(📌) 아이콘**. 켜 두면 새 야장을 열 때 그 값이 자동으로 채워진다.

### 고정 대상 — 이 6개만 (부사장 확정)
| # | 칸 | 기본 상태 |
|---|---|---|
| 1 | 대분류 | 꺼짐 |
| 2 | 연도차수 | 꺼짐 |
| 3 | 조사일 | **꺼짐 (권장 유지)** |
| 4 | 날씨 | 꺼짐 |
| 5 | 조사자 | 꺼짐 |
| 6 | 조사기관 | 꺼짐 |

그 외 칸(지점명·하천명·사업장·위도·경도·대권역명·중권역명·하천유형)은 **고정 대상이 아니다.** 압정 아이콘을 달지 않는다.

### 동작
1. 압정을 켜면 그 순간의 값이 `AppSettings` 에 저장된다(앱을 껐다 켜도 유지).
2. 새 야장(또는 분류군 변경 후 새 세션)을 열면 켜진 칸만 자동 입력된다.
3. **고정으로 들어간 값은 눈에 보이게 한다** — 칸 배경 연한 노랑(`#FFF7E6`), 압정 아이콘 채워진 상태.
4. 저장 직전(임시 저장·보고서 엑셀·일괄입력용 모두) 상단에 한 줄 안내: `고정된 값 N개가 그대로 들어갑니다 — 조사일 2025-04-28 · 날씨 맑음 …` 안내만 하고 막지는 않는다.
5. 조사개황 영역 우측에 [고정 모두 해제] 버튼.
6. 사용자가 그 칸을 직접 고치면 고정값도 새 값으로 갱신된다(압정은 켜진 채).

### 맹점
1. **조사일 고정이 가장 위험하다.** 지난 조사일이 그대로 남아 다른 날 자료에 붙는다. 기본 꺼짐 + 켜져 있을 때 저장 시 조사일을 굵게 표시.
2. **대분류를 고정하면 지점 목록이 바뀐다.** 대분류가 자동 입력되어도 **지점명은 항상 비운다.** (`SiteResolver.ByProject` 의 대분류 격리 규칙을 절대 완화하지 말 것.)
3. **연도차수 고정**은 차수가 바뀌는 시점에 사고가 난다. 연도차수 문자열의 연도 부분이 오늘 연도와 다르면 칸 옆에 작은 경고 아이콘.
4. **분류군을 바꾸면** 고정값은 그대로 유지된다(6개 모두 분류군 공통 항목이므로). 분류군별로 따로 저장하지 말 것.
5. `AppSettings` 스키마 변경 시 기존 설정 파일 호환 — 없는 키는 기본값(꺼짐)으로 읽는다.
6. 압정 아이콘은 MahApps.Metro.IconPacks 에 이미 있는 것 사용(`PackIconMaterial Kind="Pin"` / `PinOff`). 새 아이콘 리소스 추가 금지.

## B-1. 지점 지도 팝업 + 지도 이미지 교체  (≈2일)

### 무엇을
조사개황의 [지도] 버튼을 누르면 **지도 이미지 한 장**이 뜨고, **지금 입력되어 있는 위·경도 한 점만** 그 위에 표시된다.
지도 이미지는 조사자가 **설정 화면에서 직접 교체**할 수 있다.

### 화면 1 — 지도 팝업
- 진입: 조사개황 우측 [지도] 버튼. **위도·경도가 둘 다 채워져 있을 때만 활성**.
- 지도 이미지 원본 비율 유지, 창 크기에 맞춰 확대(보간 `HighQuality`). 확대/축소·이동 지원(마우스 휠 + 드래그).
- **마커는 딱 하나** — 현재 입력된 좌표. 빨간 원 + 흰 테두리 + 십자선, 그 옆에 `지점명 (위도, 경도)` 라벨.
  지도 이미지에 이미 인쇄되어 있는 St 마커들은 배경 그대로 둔다. **앱이 다른 지점을 덧그리지 않는다.**
- 상단에 지도 선택 콤보(등록된 지도 목록) + [지도 관리] 링크.
- 좌표가 선택된 지도 범위 밖이면 마커 대신 안내: `이 좌표는 「곡교천 권역 2026 (기준)」 범위 밖입니다. 다른 지도를 고르거나 지도를 추가하세요.`
- 등록된 지도가 하나도 없으면: `등록된 지도가 없습니다. 설정 → 지도 관리에서 추가하세요.`

### 화면 2 — 설정 → 지도 관리 (교체 기능)
1. 목록(이름 · 파일 · 크기 · 보정 여부) + [추가] [교체] [이름변경] [삭제] [위/아래]
2. **[추가]** → png/jpg 선택 → `maps\` 로 복사 → 보정 화면으로 이동
3. **보정 화면 (2점 방식)**
   - 지도를 띄우고 "기준점 1을 클릭하세요" → 클릭 위치 기록 → 위도·경도 입력(십진수 또는 도분초)
   - 같은 방식으로 기준점 2
   - [계산] 누르면 두 점으로 축척·원점을 구해 `calibration` 과 `bounds` 를 만든다
     ```
     ax = (px2-px1)/(lon2-lon1)      cx = px1 - ax*lon1
     ay = (py2-py1)/(lat2-lat1)      cy = py1 - ay*lat1
     → x = [ax, 0, cx],  y = [0, ay, cy]
     ```
   - 계산 후 **검증**: 등록된 다른 지점 좌표들을 찍어 보여주고 "위치가 맞습니까?" 확인받는다
4. **[교체]** → 같은 id 의 이미지 파일만 바꾼다. **가로·세로 픽셀이 이전과 다르면 보정을 무효화하고 재보정을 요구한다.**
5. [maps.json 내보내기] / [maps.json 가져오기] — 메일로 받은 갱신 자료를 통째로 반영하는 통로. 가져오기는 png 를 포함한 zip 도 허용.

### 맹점
1. **지도가 곡교천 권역뿐이다.** 오산천·원천리천·생태현황 지점에서 [지도] 를 누르면 범위 밖으로 뜬다. 버튼을 없애지 말고(나중에 지도가 추가될 수 있으므로) 안내 문구로 처리한다.
2. **좌표 형식.** 야장 입력값이 십진수(`37.185467`)인지 도분초(`37°13'14.86"`)인지 섞여 들어온다. 파서는 둘 다 받아야 하고, 실패하면 마커를 찍지 말고 `좌표 형식을 읽을 수 없습니다` 로 처리한다. **0 으로 대체하지 말 것.**
3. **2점 보정의 한계.** 북쪽이 위인(회전 없는) 지도만 정확하다. 기울어졌거나 경사 촬영된 지도는 맞지 않는다 — 보정 화면에 그 조건을 명시한다.
4. **기준점 두 개가 너무 가까우면** 오차가 크게 벌어진다. 두 점 사이 픽셀 거리가 이미지 대각선의 30% 미만이면 경고하고 진행을 막는다.
5. **이미지 해상도 변경.** 같은 지도를 더 큰 해상도로 다시 받으면 기존 보정값은 전부 틀린다(§4번 규칙으로 차단). `maps.json` 에 width/height 를 반드시 저장한다.
6. **위성 지도 저작권.** 3장 모두 위성영상 캡처다. 앱 안에서 보는 용도로만 쓰고, 앱이 이 이미지를 다시 내보내거나 인쇄물에 넣는 기능은 만들지 않는다.
7. **파일 경로에 한글·공백**이 들어간다. `Path.Combine` 사용, 문자열 이어붙이기 금지. `maps.json` 은 **UTF-8 (BOM 없음)** 으로 읽고 쓴다.
8. **`maps` 폴더가 없을 때** 앱이 죽지 않아야 한다. 없으면 만들고, 기본 지도 3장은 설치 시 함께 배포한다.
9. **팝업이 야장을 가리지 않게** — 모달로 띄우되 창 크기 기억(`AppSettings`), ESC 로 닫기.
10. **St.12 잔차 5.6픽셀**은 기준 지도 자체의 마커 위치 문제로 보인다. 앱 버그로 오해하지 말 것.
