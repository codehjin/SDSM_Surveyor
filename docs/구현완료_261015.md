## 2. 직접 확인해 주실 것

자동 검증(화면 하네스 120항목 · 기준 엑셀 20개 대조 · 빌드 경고 0)은 모두 통과했습니다.
아래는 **실제 키보드·실제 창**으로만 확인할 수 있는 것입니다.

### 2-1. B-2 한글 입력 (가장 중요)
자동 검증은 한글 입력기 없이 했습니다. 실제 입력으로 확인해 주세요.
- [ ] 저서동물 그리드 맨 아래 새 행 국명 칸에 **`방울하루살이`** 를 한글로 쳤을 때 `바ㅇ…` 으로 끊기지 않고 그대로 들어간다
- [ ] 같은 방법으로 **`강하루살이`**
- [ ] 국명 칸에서 드롭다운 후보를 **한 번 클릭**하면 바로 선택된다
- [ ] 빠른추가 검색창에 `방울하루살이` 를 쳐도 끊기지 않는다

### 2-2. B-5 닫기
- [ ] 앱을 켜서 아무것도 안 하고 닫으면 묻지 않는다
- [ ] 자료함에서 예시 세션을 불러온 직후 닫으면 묻지 않는다
- [ ] 종을 하나 넣고 닫으면 묻는다 → [취소] 창 유지 / [아니요] 저장 없이 닫힘 / [예] 저장 후 닫힘
- [ ] 대분류·연도차수·지점 중 하나라도 비운 채 [예] → "비어 있는 칸" 안내가 뜨고 창이 남는다

### 2-3. 나머지 (짧게)
- [ ] 어류 빠른추가 `ㅍㄹㅁ` → 후보가 바로 보이고 ↓ → 개체수 → Enter 로 추가된다. 같은 종을 한 번 더 넣으면 칩에 `(합산)`
- [ ] 조류에 같은 종 두 번 → 행 두 개 + 국명 옆 `같은 종 2행`
- [ ] 어류 조사환경 하상구성 칸에 `12.5`·`a` 가 들어가지 않는다 / 저서 하상 합계가 100 이 아니면 접힌 요약줄에도 경고
- [ ] 어류 조사환경 「흐름상태(채집)」 에서 여울·소를 고르고 임시 저장 → 자료함에서 다시 열면 그대로

### 2-4. 관리자 앱 검수 (지시서 §10)
B-7 이 멈춰 일괄입력용 파일은 **현행 형식**(빈 통합문서에 값만)입니다. 그래도 이번 변경(흐름상태(채집) 16행 이름 · 하상 정수)이
관리자 일괄등록에서 오류 없이 읽히는지 보려면, 곡교천4 2025분기3차 예시로 일괄입력용 7개를 만들어 **검수만**(저장하지 않음) 해 주세요.

## 3. 결정이 필요한 것 — B-7 (일괄입력용 양식 내장)

왕복 시험에서 **방류하천 어류 양식 3개가 Telerik 으로 저장되지 않습니다**(파일이 만들어지지 않음).
원인은 양식 69·70·74행의 `CHOOSE(X$17, …)` — 17행(하천차수)이 빈 레코드 열에서 Telerik 이 예외를 냅니다.
내장본은 레코드 값을 지우므로 이 상태가 항상 생깁니다. 아래 중 하나를 골라 주시면 이어 갑니다(자세한 내용: 작업로그 B-7 절).

- (가) 어류 내장본의 레코드 열을 **Q 한 열만** 남기고, 하천차수가 비면 내보내기 전에 알리고 막는다 — 수식 내용은 그대로
- (나) 어류 내장본의 FAI `CHOOSE` 를 `IF(X$17="","",CHOOSE(…))` 로 감싼다 — 발주처 양식 수식이 달라짐
- (다) 어류만 현행 방식 유지 + 라벨 열만 덧붙임 — 양식 내장은 아님
- (라) 다른 엑셀 라이브러리 — 새 패키지라 별도 합의 필요

함께: Telerik 이 붙이는 `License` 시트(현행 내보내기에도 있음), 저서 오산천·원천리천 파일 열기·저장이 5초 초과(최대 7.87초).
