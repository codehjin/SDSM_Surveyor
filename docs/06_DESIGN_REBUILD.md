## 2. 현재 자산 (유지할 것 / 버릴 것)

### 유지 (검증된 것)
- 디자인 토큰: `Styles\Colors.xaml`, `Styles\Styles.xaml`
  - 강조색 `#0381FE`, 셸 딥네이비 `#1E232E` 계열, 분류군별 색(어류 `#00B8D4` · 저서 `#651FFF` · 조류 `#9E9D24` · 포유류 `#FE9900` · 양서파충류 `#CC33FF` · 서식수변 `#37474F` · 수질 `#2979FF`)
  - 폰트 맑은 고딕 14.5 / 타입스케일 26·19·15·11.5 / 값 30 · 등급 24
- 상단 딥네이비 캡션바(50px) + 중앙 타이틀 — 관리자와 통일된 형태
- 분류군 세그먼트 탭(RadioButton 기반, 분류군 색 표시등)
- 접이식 조사개황(지점당 1회 입력 후 접기)

### 재설계 대상
- 화면 내부 배치 전반(그룹 순서·열 수·여백 리듬·카드 구획)
- 실시간 통계/지수 패널(현재 우측 320px 고정)
- 그리드 밀도·컬럼 폭·헤더 스타일
- 하단 상태바/액션 버튼 구성(버튼이 4개로 늘어남)
- 수질·서식수변의 빈 공간 문제(항목이 상단 한 줄에만 몰림)

## 3. 제약 조건 (반드시 지킬 것)

1. **라이선스**: 삼성 로고·브랜드 남색·SamsungOne 서체 **사용 금지**. "삼성 느낌"은 레이아웃·색 운용·절제된 타이포로만 표현한다.
2. **Telerik StyleManager**: `RadTabItem` 등 Telerik 컨트롤에 Style을 통째로 지정하면 테마 템플릿이 벗겨진다. `90_TECH_NOTES.md` §2 참조.
3. **현장 사용성**: 조사자는 야외·노트북 환경에서 **빠르게 많이 입력**한다.
   - 키보드만으로 연속 입력 가능해야 한다(Tab·Enter 흐름)
   - 클릭 수 최소화, 종 입력이 화면의 주인공
4. **정보 위계**: 자동계산 지수(FAI·BMI·등급)는 **입력 결과의 피드백**이지 입력 대상이 아니다. 시각적으로 구분되어야 한다.
5. **경고 표시**: 이상치 경고는 **비차단**. 붉은 강조는 쓰되 작업을 막는 인상을 주지 않는다.

## 4. Claude Design이 설계할 항목

아래를 이 문서에 **채워 넣는다**(섹션 5로 추가).

1. **레이아웃 원칙** — 그리드 시스템, 여백 스케일, 카드 구획 규칙
2. **화면별 와이어프레임**
   - 공통 셸(캡션바·탭바·상태바)
   - 종 입력형 2종(어류·저서동물): 조사개황 / 빠른추가 / 그리드 / 지수 패널의 배치·비율
   - 관찰형 3종(조류·포유류·양서파충류): 컬럼이 많은 그리드(흔적 12종) 처리 방안
   - 폼형 2종(수질·서식수변): 항목이 많은 폼의 열 구성
   - 자료함(세션 목록), 동기화 창
3. **컴포넌트 스펙** — 폼 필드, 그룹 헤더, 표 헤더, 지수 카드, 등급 뱃지, 경고 표시, 버튼 계층(주요/보조/위험)
4. **토큰 갱신안** — 색·타이포·여백·모서리·그림자 최종값
5. **상태 정의** — 기본/포커스/오류/경고/비활성/읽기전용

## 6. 구현 지침 (Claude Code)

- 스펙 확정 후 `Styles\Colors.xaml`·`Styles\Styles.xaml`을 **먼저** 갱신하고, 화면은 그 토큰만 참조하게 한다. 화면에 색·수치를 직접 쓰지 않는다.
- 한 화면(어류)을 기준으로 완성해 승인받은 뒤 나머지 6개에 복제한다.
- 리팩토링(5단계)에서 만든 공통 컨트롤(조사개황·빠른추가 바·상태바)을 고쳐 전체에 반영한다.
- 아이콘 Kind는 사용 전 DLL에서 존재를 확인한다(`90_TECH_NOTES.md` §0).
