### 2-1. 등록 방법과 이유
- **UI Automation 불가** — 관리자 `App()` 이 `AutomationManager.AutomationMode = Disabled` 로 텔레릭 컨트롤을 외부 UIA 에서 숨긴다(단추·그리드가 트리에 안 나옴).
- 그래서 **같은 프로세스 하네스**(`도구\admin_harness`)로 실제 관리자 `App`·DI·`Bulk*Control` 을 그대로 띄우고, 화면의 `RadButton.Command`(`엑셀자료 가져오기` → `변환된 자료 일괄 저장`)를 그대로 실행했다. 파일 열기·저장 대화상자와 MessageBox 는 Win32 로 자동 응답(대화 문구 기록).
- **DB 쓰기 전 확인** — 하네스가 `GB.SqliteDataSource` 를 시험 DB 로 지정하고, 명령 실행마다 `AssertTestDb`(경로가 `_test_db` 아래 + 하드링크와 같은 파일 ID)로 확인. 확인 실패 시 중단하도록 했다(실패 0회).
- 화면 확인(7절)은 `MsgAuto.NeverSave`(저장·삭제·수정을 묻는 창은 모두 [아니요]/[취소]) — 앞뒤 시험 DB 해시 `f36cf9be874c5a9f` 같음.

- **null 과 0 구분 유지** — 조류·포유류·양서 개체수·흔적 빈칸은 DB NULL, 0 은 0.
- 틀린 학명은 조사자가 종목록 학명으로 바꿔 내보냄 · 목록 밖 종(시험목록밖…)은 그대로 저장.

- 날씨 '비(눈)' 그대로 저장(오류 없음).
