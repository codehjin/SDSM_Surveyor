## 2. 지금 지킬 운영 규칙 (개발 기간 중)

1. **기준 실데이터 = `3_publish\SDSMDB.sqlite`**. 재산출·취합 테스트는 이 파일이 대상이다.
2. **`bin\Debug`의 DB는 시험용 사본**이다. 실데이터가 아니므로 개발 중 마음껏 써도 된다.
   (오히려 실데이터와 분리되어 있어 안전하다)
3. 🚫 **csproj에 DB 복사 설정(`Content` + `CopyToOutputDirectory`)을 추가하지 말 것.**
   추가하는 순간 빌드·게시 때마다 **실데이터가 초기 DB로 덮어써진다.**
4. 분석·검증 시 DB는 **사본을 떠서** 열고, 원본은 읽기만 한다(`-wal`/`-shm` 생성 방지).

## 3. 선결 과제 — 지점명 체계 (재구축 전 반드시)

지금 상태로 재입력하면 아래 사고가 그대로 재현된다.

### 확인된 사례 — 곡교천2 / 곡교천3 뒤바뀜

엑셀의 **곡교천3** 자료가 DB에는 **곡교천2**로 들어가 있다(2023~2025, 18건).

| 차수 | 엑셀 곡교천3 | DB 곡교천2 |
|---|---|---|
| 2023분기1차 | 18.8 · E | 18.8 · E |
| 2023분기2차 | 68.8 · B | 68.8 · B |
| 2023분기3차 | 56.3 · C | 56.3 · C |
| 2024분기1차 | 43.8 · C | 43.8 · C |

값이 정확히 일치한다 → **계산 문제가 아니라 지점명 매핑 사고**다.
원인은 **연도별 지점명 변경**: 조사지점 시트 기준 `22~25년 곡교천-2` → `26년 곡교천3`.

→ `04_FEATURE_SITE_SESSION.md` 의 **`sites.json` 지점 마스터**(연도별 표기 매핑 포함)를 먼저 확정한다.
그래야 재입력 시 각 자료가 제자리를 찾는다.

## 4. 재구축 절차 (개발 완료 후)

### 4-1. 사전 점검
1. **전 분류군 "엑셀에 없는 DB 레코드" 조사** (읽기 전용)
   - 어류는 완료: 829건 중 18건이 엑셀에 없었고, 전부 위 곡교천2/3 사례로 설명됨 → 실질 유실 위험 없음
   - **조류(3,554) · 포유류(630) · 양서파충류(611) · 수질(1,277) · 서식수변(90)** 은 미확인. 같은 점검 필요
   - 엑셀에 없는데 설명되지 않는 레코드가 있으면 **재입력 시 유실된다** → 별도 보존 대책 수립
2. 엑셀 내부 중복 확인 — 어류에서 4건 발견(오산천1·2, 진위천1·2). 같은 조합인데 값이 다르다.
   예: `2025분기1차 오산천1` 총점 62.5 vs 56.3 → **어느 쪽이 맞는지 사용자 확인 필요**
3. 미취합 자료 확인 — 어류 엑셀 937건 중 **126건**이 DB에 없다. 취합 대상인지 판단

### 4-2. 실행
4. **백업**: `3_publish\SDSMDB.sqlite` → `SDSMDB_backup_YYYYMMDD.sqlite` (복사, 이동 금지)
5. 지점 마스터(`sites.json`) 기준으로 **지점명 정규화** 후 일괄입력
6. **대조 검증**: 재입력 결과의 FAI·BMI·등급이 **원본 엑셀의 계산값과 일치**하는지 확인
   - 단, 아래 확정 수정으로 **의도적으로 달라지는 항목**이 있다(§4-3)
7. 개발용 `bin\Debug` DB를 재구축본으로 **교체**해 두 폴더를 일치시킨다

### 4-3. 재구축 후 예상되는 정상적 차이

`12_CALC_FIX.md` 의 확정 수정 때문에 과거 값과 달라지는 것이 있다. **오류가 아니다.**

| 항목 | 변화 | 영향 |
|---|---|---|
| **어류 0종 → 0점·E** | 기존 `37.5·D` → `0·E` | 게시본 기준 **7건**(2012·2017×4·2021·2024) |
| **M8 실수 나눗셈** | 비정상종 비율이 실제 값으로 | **과거 데이터 영향 없음** — 비정상종 개체수가 한 건도 입력되어 있지 않다 |

> 0종 7건은 **원본 엑셀도 `0.0·E`로 계산**하고 있었다. 관리자 앱이 37.5·D로 바꿔버린 것이므로,
> 이번 수정은 **조사자의 원래 판단을 복원**하는 것이다. → 근거는 `90_TECH_NOTES.md` §5

## 6. 미결 사항 (사용자 판단)

1. **엑셀 내부 중복** — `2025분기1차 오산천1` 이 두 파일에 있고 총점이 62.5 / 56.3 으로 다르다.
   진위천1·2는 같은 파일 안에서 두 번 나오며 31.3 / 68.8 로 다르다. **어느 쪽이 정본인가.**
2. **미취합 126건** — 취합 대상인지, 의도적으로 제외한 것인지.
3. **DB 경로 정책** — 재구축 후에도 실행 폴더 기준을 유지할지, 고정 경로(예: `2_database\`)로 옮길지.
   고정 경로로 옮기면 분기가 원천 차단되지만, 개발 중 시험 데이터가 실데이터에 섞이지 않도록
   개발 빌드는 별도 경로를 쓰게 구분해야 한다.
