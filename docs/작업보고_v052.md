## 1. 바뀐 것

### 1-1. 흰 화면 스위치(§25)

- `Helpers\RenderModeSwitch.cs`(새): `Matches(파일 이름)` = 확장자를 모두 뗀 이름이 `software_render`(OrdinalIgnoreCase) · `HasSwitchFile(폴더)` = 그 폴더의 **파일**(하위 폴더 · 같은 이름 폴더는 안 봄) 중 하나라도 맞으면 true · 읽기 예외는 false · `Apply()` = `AppContext.BaseDirectory` 를 보고 `RenderOptions.ProcessRenderMode = RenderMode.SoftwareOnly` · `IsSoftware` · `Description`.
- `App.xaml.cs` 생성자 첫 줄(테마 · 한글화 · DI · 리소스보다 앞).
- 정보 창: 「빌드 날짜」 아래 「화면 그리기」 줄 = `그래픽카드` / `소프트웨어(software_render 파일)`.
- 판정 표(하네스): `software_render` · `software_render.txt` · `software_render.txt.txt` · `SOFTWARE_RENDER.TXT` · `Software_Render.bak` → 켜짐 / `software_render_old.txt` · `software_rendering.txt` · `old_software_render.txt` · `readme.txt` · 파일 없음 · 없는 폴더 · 이름이 software_render 인 폴더 → 꺼짐.
- ⚠ 앱 코드에 시험용 분기는 없다. 하네스가 소프트웨어로 그려야 하면 하네스 실행 폴더에 파일을 둔다(이번 하네스는 화면 사진을 RenderTargetBitmap 으로 찍어 필요 없었다).

### 1-3. 알림 띠(§27-2)

- `ViewModels\NoticeBandViewModel.cs`(새): `Receive` → 다른 스레드면 UI 로 넘김 · 빈 글 무시 · 지금 보이는 글과 같으면 시간만 새로 · 기다리는 줄에 같은 글이 있으면 안 쌓음 · 줄에 넣고 없으면 바로 보임. `DispatcherTimer` 로 성공 `SuccessTime` 4초 · 주의 `WarnTime` 8초 뒤 다음 것. `Text` = 줄바꿈을 ' · ' 로 이은 한 줄(넘치면 말줄임) · `FullText` = 툴팁(여러 줄 그대로) · `DismissCommand` = [×].
- `Views\UserControls\NoticeBand.xaml(.cs)`(새): Border(스타일 `NoticeBandBorderStyle`) + 아이콘 + 글(`NoticeBandTextStyle` · `LiveSetting=Polite`) + [×](`Focusable=False` · 이름 「알림 닫기」). DataContext = DI 싱글턴.
- `TaxonStatusBar.xaml`: 바깥을 StackPanel 로 감싸 **띠 → 상태 바** 순. 띠가 없으면 접혀 자리를 차지하지 않고, 있으면 한 줄만큼 그리드가 줄어든다(입력 칸을 덮지 않는다).
- `App.OnStartup`: CrashGuard 다음에 띠 VM 을 만든다 — 분류군 고르기 창 → 자료함에서 보낸 알림도 야장 창이 뜨면 보인다.
- `Styles.xaml`: 띠 스타일 2개(토큰만 · hex 없음). `tools\contrast_audit.py`: 띠 글자 · 아이콘 조합 4건 등록(성공 = AccentOnSurface / AccentSurface · 주의 = DangerOnSurface / DangerSurfaceSoft — 이미 통과한 조합과 같은 색).
- `TaxonEntryViewModelBase.NotifyExported`: 확인할 것(빈 행 · 양식 외 값)이 없으면 **띠를 보내지 않는다**(2-3 ①).

### 1-4. 조사불가 사유(§27-4)

- `Models\FormChoices.UnavailableReason`(새 · 이름 저장) — 어류 · 저서 VM 의 `IsUnavailable` 도 이 목록을 본다(종전 VM 마다 같은 배열 · SDSM_Core 와 같은 '공백 빼고 같은 글' 판정 그대로).
- 어류 「조사불가 사유」 · 저서 「채집불가시(사유)」: 여러 줄 글 칸 → `SingleChoiceBox`(Sm 폭 · [비우기] · 예전 값은 「값 (양식 외)」 로 고른 채 + 칸 아래 경고).
- `ChoiceWarning` 에 사유를 더함 → 조사환경 접힌 줄 · 저장 알림(양식 외 값)에 '양식 외 값: 조사불가 사유 접근불가(홍수) — 지우지 않음, 확인하세요'. 사유가 바뀌면 경고 줄도 다시 그림.
- 서식수변: 화면 경고 「조사불가(접근불가)로 등급 산정에서 빠집니다. 조사불가시 글에 '접근불가' 가 들어 있으면 등급이 '-' 가 됩니다(건천화 · 준설 · 공사중 등 다른 사유는 등급에 영향이 없습니다).」 · 툴팁 같은 뜻. 동작 · 칸 모양은 그대로(자유 글).

### 3-1. 판단해서 정한 것

- **조사불가 예전 글은 [일괄입력용] 을 막지 않는다** — 막힘 규칙은 '관리자 일괄등록이 받지 못하는 값'(형변환 실패)이다. 관리자 일괄등록은 사유를 글자로 읽어 저장하고(`BulkFishControlViewModel` · `BulkBenthosControlViewModel` 읽기 확인) 다른 글이면 등급을 계산할 뿐이라 막을 근거가 없다. 경고만 한다.
- 띄어 쓴 '접근 불가' 같은 예전 글은 SDSM_Core 가 공백을 빼고 보므로 등급 '-' 이지만 고르기 칸에는 '(양식 외)' 경고가 뜬다 — 다시 고르면 없어진다.
- 포유류 상태 바: 흔적 합은 「n흔적」, 행 수는 「기록 n건」 — '흔적 n흔적' 이 겹치지 않게 행 수 이름을 바꿨다.
