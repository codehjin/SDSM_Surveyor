기준 문서
design.md 토큰 전부 준수 — 간격 6단계, 입력 36, 탭 44, 행 34, 본문 최대폭 1240, 코너 4/8, 그림자 없음. 열 폭·대비 규칙도 그대로.
브랜드
삼성 로고·브랜드 남색·SamsungOne / One UI 서체는 사용하지 않음. "삼성다움"은 제품 UI 계열 파랑(#0381FE), 절제된 여백, 카드형 정보 구조, 접근성 준수로만 표현.
서체

화면
7개 분류군 중 어류 1개만 그렸습니다. 방향이 정해지면 패턴 B(관찰형 2단 행)·C(폼형)로 확장합니다.
최신성
구형 인상의 원인을 ① 서체 ② 2px+ 테두리·그라디언트 ③ 회색 위 회색(정보 위계 없음) ④ 여백 불균일로 봤고, 세 시안은 이 넷을 서로 다른 강도로 걷어냅니다.
