# Handoff: 삼성 DS 모니터링 야장 (조사자 앱) UI 리디자인

## 개요

`SDSM_Surveyor` (.NET 8 WPF · Telerik UI for WPF) 조사자 앱의 화면 리디자인이다.
조사자가 현장에서 종이 야장에 적고 사무실 PC에서 엑셀로 옮겨 적던 작업을 앱으로 대체하는 것이 목적이며,
발주처 요구는 ① 구형 인상 제거(최신성) ② 입력 속도 ③ 삼성 브랜드 자산을 쓰지 않는 "삼성다움" 이다.

확정 방향은 **턴 3 (3a/3b/3c)** 이다. 턴 1·2는 의사결정 이력으로만 남겨 둔 것이며 구현 대상이 아니다.

핵심 변경 4가지:

1. **단일 분류군 모드** — 담당자는 자기 분류군만 쓴다. 첫 실행에서 분류군을 고르면 **상단 분류군 탭 행(44px)을 표시하지 않는다.** 재선택은 캡션 바의 분류군 칩에서 한다.
2. **우측 결과 레일 제거** — 지수/총계를 본문 상단 가로 스트립으로 올렸다. 본문 가용폭이 약 320px 늘어나 국명·학명 열이 뭉개지지 않는다.
3. **조사환경·건강성 접기** — 두 섹션을 한 줄 요약(36px)으로 접으면 종 그리드가 12행 → 20행이 된다. 접힘 상태에서도 요약줄이 값을 계속 보여준다.
4. **야외(현장) 모드 삭제** — 사무실 PC 입력 대체 앱이므로 불필요. 종전 '야외 모드' 버튼 자리가 분류군 재선택 칩이 되었다.

## 이 디자인 파일에 대하여

이 묶음의 `조사자앱 시안.dc.html` 은 **HTML로 만든 디자인 레퍼런스**다. 의도한 모습과 동작을 보여주는 시안이며,
**그대로 복사해 쓸 프로덕션 코드가 아니다.** 실제 작업은 이 화면들을 **기존 코드베이스의 환경
(.NET 8 WPF + Telerik `AllControls.Xaml` 2026.2.520 · Windows11 테마 · CommunityToolkit.Mvvm)** 에서
그 저장소의 확립된 패턴대로 재현하는 것이다. HTML/CSS를 XAML로 옮기는 것이 아니라, **치수·색·문구·정보 구조를 옮긴다.**

반드시 함께 읽을 저장소 문서 (이 README보다 우선한다):

- `design.md` — 토큰·색·타이포·골격·접근성 기준. 이 시안은 이 문서를 준수하도록 그렸다.
- `CLAUDE.md` — MVVM·DI·세션 저장·생태 계산 규칙. **계산식은 절대 손대지 않는다** (`SDSM_Core/Ecology/`).

## 충실도

**High-fidelity (hifi).** 색·치수·문구가 확정값이다. 단, WPF에서는 `design.md` 토큰 키로 구현한다 —
**XAML에 `#RRGGBB` 리터럴을 쓰지 않는다.** 아래 문서의 hex는 어느 토큰인지 식별하기 위한 표기다.
시안에 없는 상태(hover·pressed·disabled)는 Telerik Windows11 테마 기본값을 따른다.

`design.md` 에 없어 **새로 추가해야 하는 토큰은 §"신규 토큰" 절에만** 있고, 그 외에는 기존 토큰으로 전부 표현된다.

## 화면 / 뷰

기준 창: `MinWidth 1280 / Width 1440`, `MinHeight 760 / Height 860`. 시안은 1440×860 기준으로 그렸다.
세로 구성(1440×860, 접힘 상태 = 3a):

```
캡션 바              50px   (WindowChrome CaptionHeight 50)
본문 여백            12px
조사개황 요약 카드   48px
간격                  8px
조사환경 요약 줄     36px   ← 접힘
간격                  8px
건강성 요약 줄       36px   ← 접힘
간격                  8px
빠른추가 바          56px
간격                  8px
종 그리드            나머지 (약 480px = 머리글 34 + 행 34×12 + 합계 36)
본문 하단 여백        8px
상태바               48px
```

펼침 상태(3b)에서는 조사환경 카드(약 168px, 2줄 폼) + 건강성 카드(약 108px)가 들어가고 그리드가 12행이 된다.
1280×760 에서도 같은 골격이 성립해야 하며, 세로 스크롤은 허용한다(`design.md` §2.5).

### 1. 첫 실행 — 담당 분류군 선택 (3c)

- **목적**: 담당 분류군 1개를 고른다. 이후 그 분류군의 야장만 열리고 탭 행은 표시되지 않는다.
- **레이아웃**: 캡션 바 50px 아래 전체 영역에 카드 1개를 가운데 정렬. 카드 폭 **840px**, 패딩 **32px**(`Space2Xl`), 코너 **8**(`CornerRadiusMd`), 테두리 1px `PrimaryBorderColor`, 배경 흰색. 바깥 배경 `#F7F8FA`.
- **구성**
  - 제목 「담당 분류군을 고르세요」 — 26px(`PageTitleFontSize`), 행간 34, 자간 -0.3
  - 설명 1줄 — 14.5px, `SecondaryForegroundColor`, 행간 21: 「고른 분류군의 야장만 열립니다. 상단 분류군 탭은 표시되지 않고, 필요하면 캡션 바에서 언제든 바꿀 수 있습니다.」
  - 분류군 타일 **4열 그리드**, 간격 12px(`SpaceMd`), 타일 높이 **96px**, 패딩 16px, 코너 8
    - 타일 내부: 상단에 분류군 색점 11×11 원형, 하단에 분류군명 19px SemiBold(`SectionTitleFontSize`) + 유형 설명 12px(`CaptionFontSize`, `#666`)
    - 유형 설명 문구: 어류 「종 입력형 · FAI」 / 저서동물 「종 입력형 · BMI」 / 조류 「관찰형 · 2단 행」 / 포유류 「관찰형 · 흔적 12칸」 / 양서파충류 「관찰형 · 2단 행」 / 수질 「폼형 · 항목별 등급」 / 서식수변 「폼형 · 10항목 평가」
    - 선택된 타일: 테두리 **2px `AppAccentColor`** + 배경 `#F5FAFF`(신규 토큰 `AccentSurfaceColor`)
    - 8번째 칸은 점선 테두리 안내: 「여러 분류군을 맡았다면 나중에 바꿀 수 있습니다」 (13px, `#666`)
  - 구분선 1px, 하단 액션 행: 좌측 체크박스 「다음 실행에도 {분류군}로 시작」(14.5px), 우측에 보조 버튼 「자료함에서 이어하기」, 주요 버튼 「{분류군} 야장 열기」(`PrimaryActionBackBrush` 채움 + 흰 글자, 높이 36 = `InputHeight`)
- **동작**: 「야장 열기」 → 메인 창. 체크가 켜져 있으면 선택을 설정에 저장하고 다음 실행부터 이 화면을 건너뛴다(캡션 칩에서 언제든 변경 가능).

### 3. 메인 — 펼침 상태 (3b)

접힘 줄 2개가 카드 2개로 바뀐다. 나머지는 3a와 동일.

- **조사환경 카드**: 패딩 16, 코너 8. 머리글 「조사환경」 19px + 우측 「접기 ⌃」. 폼 칸은 `design.md` §2.3 4단 규격 그대로 — 하천형태 176(`FieldMd`), 흐름상태·채집도구 128(`FieldSm`), 유폭·수심 96(`FieldXs`), 조사불가 사유 176. 라벨 15px + 입력 36, 라벨↔입력 간격 4, 칸 사이 12.

  세로 구분선 1px 우측에 요약 수치: 총 종수 / 총 개체수 / 우점종 / 보호종 / 교란종 — 각 12px 라벨 + 30px Bold 값. 맨 우측에 경고 박스(배경 `#FDF3EE`, 글자 `#992700`, 코너 8, 패딩 8 12, 13px): 「⚠ 7행 개체수 미입력 — 미입력과 0 은 다르게 저장됩니다」

## 상호작용 & 동작

| 대상 | 동작 |
|---|---|
| 첫 실행 분류군 선택 | 타일 클릭 → 선택 표시(2px 강조 테두리) → 「야장 열기」로 진입. 체크 시 설정에 저장 |
| 분류군 칩 | 클릭 → 팝오버(150ms ease-out). 항목 선택 시 즉시 전환, **입력 자료 유지**, 탭 행은 계속 표시하지 않음 |
| 조사환경/건강성 접기 | 180ms ease-out 높이 전환. 접힘 상태를 **세션에 저장**해 다음 실행에도 유지 |
| 빠른추가 | 초성 검색 → 종 선택 시 자동으로 개체수 칸 → `Enter` → 행 추가 + 검색창 복귀. 추가된 행 배경 강조 1.2초 |
| 붙여넣기 | `Ctrl+V` 로 엑셀 다중 행(VM 이 직접 파싱) |
| 그리드 키보드 | `Tab`/`Shift+Tab` 다음·이전 칸, `Enter` 확정 + 아래 행 같은 칸, `F2` 편집, `Esc` 취소 |
| 포커스 표시 | 모든 포커스 가능 요소에 **2px `AppAccentColor` 링**. 제거 금지(§11.1) |
| 유효성 검사 | 칸을 벗어날 때(LostFocus). 타이핑 중 빨간 표시 없음 |
| 저장 상태 | 상태바에 색+아이콘+글자 3중 표시. **동기화 실패 표시는 자동으로 사라지지 않는다** |
| 창 닫기 | 미저장 변경이 있으면 건수를 명시: 「『어류 · 곡교천1』 입력 8건이 저장되지 않았습니다.」 |
| 빈 상태 | 대분류 미선택 「조사개황에서 대분류를 먼저 고르세요」 / 종 미입력 「위 빠른추가로 종을 추가하세요」 |

## 에셋

- **이미지·아이콘 에셋 없음.** 아이콘은 기존 `MahApps.Metro.IconPacks` 에서 가져온다 — 시안의 🔍 ⏎ 🗂 ☁ 🗎 ⚠ ☀ 는 자리표시 문자이며, 실제로는 `ClipboardTextOutline`·`ContentSaveOutline`·`CloudSyncOutline`·`FolderMultipleOutline`·`AlertCircleOutline`·`PlusBoxOutline`·`DeleteSweepOutline` 등 §9 검증 목록에서 고른다. 새 Kind 는 DLL 존재 확인 후 사용.
- **삼성 로고·브랜드 남색·SamsungOne/One UI 서체는 사용하지 않는다.** 앱 마크는 강조색 사각형이다.
- **서체: Pretendard 확정**(SIL OFL 1.1, 브랜드 자산 아님). 배포 패키지에 폰트를 포함하고 `pack://` URI 로 등록해야 현장 PC에서 동일하게 렌더링된다. `DefaultFontFamily` 를 Pretendard 로 교체하고 맑은 고딕을 폴백으로 남긴다.
  ⚠ 시안의 서체 비교(2a Pretendard vs 2b 맑은 고딕)는 비-Windows 환경에서 렌더링됐다. **실기기에서 14.5px 렌더링을 한 번 더 확인할 것.**
