  3. .NET 을 따로 설치하지 않아도 됩니다. 단독 실행형입니다.

  ※ 처음 실행할 때 Windows 가 "PC를 보호했습니다" 창을 띄울 수 있습니다.

      목록이 열려 있으면(▼ 또는 ↓) 글자를 칠 때마다 바로 다시 걸러집니다. 이때 후보는 저절로 고르지 않으니
      ↑↓ 나 마우스로 고르세요(글자만 치고 Enter 하면 위의 규칙대로 같은 이름만 고릅니다).

  32. 저서동물 개체밀도(inds./㎡)를 함께 보여 줍니다 — 실측 개체수는 그대로 두고, 화면 건강성의 "총 개체수" 옆과
      보고서 엑셀(출현종 표의 종별 열 · 건강성평가의 채집 면적·총 개체밀도)에 개체밀도가 나옵니다.
      채집 면적 = 채집기 면적 × 조사 횟수의 합 — Surber 30×30 0.09㎡ · Surber 50×50 0.25㎡ · 에크만 0.0225㎡(15×15cm 기준).
      예: Surber 30×30 3회 = 0.27㎡ → 개체밀도 = 총 개체수 ÷ 0.27. 소수 한 자리로 보입니다.
      드렛지/D-Net 은 면적 기준이 없어 환산하지 않습니다 — 드렛지/D-Net 횟수가 있으면 "환산 불가" 로 보입니다.

■ v0.4 에서 반영한 것 (2026-10-21 관리자 연계 시험 2차)
  1. 분류군마다 조사일 — 각 분류군 화면 위쪽에 "조사일" 칸이 생겼습니다. 비워 두면 조사개황 조사일을 따르고
     (칸에 조사개황 날짜가 흐리게 보입니다), 같은 지점·차수라도 그 분류군만 다른 날 조사했으면 그 날짜를 넣습니다.
     일괄입력용 · 보고서 엑셀의 조사일은 그 분류군 조사일입니다.
     [합치기] 할 때 이미 있던 분류군의 조사일이 새 조사개황 조사일과 다르면 그 분류군 조사일로 옮겨 적고,
     확인 창에 "포유류 조사일 2025-09-06 유지", "조사자 · 김OO → 이OO" 처럼 바뀌는 것을 보여 줍니다.
     (예전에는 포유류(9월 6일)에 서식수변(10월 1일)을 합치면 포유류 조사일도 10월 1일로 바뀌었습니다)
  2. 하천명을 고칠 수 있습니다 — 지점을 고르면 지점 목록의 하천명이 들어가고, 세부 하천명(예: 원천리천 하류 "황구지천")으로
     고칠 수 있습니다. 고친 하천명은 저장·다시 열기에도 남고 일괄입력용·보고서에 들어갑니다. 지점 목록과 다르면 칸 아래에
     "지점 목록: 원천리천" 이 작게 보입니다. 지점을 다시 고르면 지점 목록 하천명으로 돌아갑니다.
  3. 개체수·하상 % 등 정수 칸에 소수점·쉼표·글자를 치면 받지 않고 칸 아래에 "정수만 넣습니다" 가 잠깐 보입니다.
     그 칸은 들어왔을 때의 값으로 돌아갑니다(예전에는 1.5 를 치면 점만 빠져 15 가 들어갔습니다).
     안내가 떠 있는 2~3초 동안은 이어 치는 숫자도 받지 않습니다 — Backspace 나 Tab 을 누르면 바로 다시 칠 수 있습니다.
     엑셀에서 여러 줄을 붙여넣을 때 정수 칸에 정수가 아닌 값이 있으면 그 칸만 비우고 넣은 뒤
     "2칸은 정수가 아니라 넣지 않았습니다(1행 6열 '1.5' · …)" 로 알립니다.
  4. 붙여넣기 중 다른 프로그램이 클립보드를 잡고 있으면 프로그램이 닫히던 문제를 고쳤습니다.
     잠깐 다시 시도하고, 그래도 안 되면 "클립보드를 읽지 못했습니다 — 잠시 뒤 다시 붙여넣으세요" 를 보입니다.
  5. 예기치 않은 오류가 나도 프로그램을 닫지 않습니다. 오류를 자료함 logs 폴더에 남기고, 화면에 입력이 있으면
     자료함 _recovery 폴더에 임시 저장한 뒤 그 위치를 알립니다(정식 자료는 덮지 않습니다).
     다음에 켤 때 "복구본이 있습니다 — [불러오기]/[나중에]" 를 묻습니다. [불러오기] 는 화면에 올리기만 하므로
     [임시 저장] 을 눌러 저장하세요. 자료함 위치: %AppData%\SDSM_Surveyor\sessions
  6. 저서동물 보고서 엑셀 — 조사불가·출현종 없음(0종)이면 DI·H'·R1·J' 를 빈칸으로 냅니다(화면·관리자와 같게).

■ v0.3 에서 반영한 것 (2026-10-20 관리자 연계 시험)
  1. 같은 대분류·연도차수·지점의 자료가 자료함에 이미 있는데 [새 지점]·[지점 복사]·[차수 복제] 로 만든 화면을
     저장하면, 덮어쓰지 않고 [합치기] · [바꾸기] · [취소] 를 묻습니다(기본 [합치기]).
     합치기 — 지금 화면에 자료가 있는 분류군만 새 값으로 바꾸고 나머지 분류군은 그대로 둡니다.
              조사개황은 지금 값으로 하되 빈칸이면 이미 있던 값을 남깁니다. 합친 결과를 알리고 화면에 다시 불러옵니다.
     (예전에는 같은 지점에 포유류를 저장한 뒤 [새 지점] 으로 서식수변을 저장하면 포유류 자료가 사라졌습니다)
  2. 어류 하천차수 — 지점을 고르면 지점 하천차수가 미리 들어갑니다(고칠 수 있음). 방류하천 지점 중 하천차수가 비어 있던
     25곳 가운데 과거 어류 기록이 한 값으로 맞는 15곳을 채웠습니다(곡교천1·3·4 · 천안천3 · 회룡천1 · 원천리천0~9).
     하천차수가 비어 있으면 건강성 FAI 를 "-" 로 보이고 "하천차수 필요" 를 알리며, [일괄입력용] 을 만들지 않습니다
     (관리자 일괄등록에서 막히는 칸이라서). 조사불가 사유가 있거나 출현종 없음(0종)을 선언했으면 막지 않습니다.
     2026년 새 지점(곡교천2 · 천안천1·2 · 회룡천2)은 과거 기록이 없어 하천차수를 직접 넣어야 합니다.
  3. 어류 비정상종(DE·EF·LE·TU) 칸은 개체수만 정수로 넣습니다. 종명은 비고에 적습니다.
     예전 자료에 "붕어(2)" 처럼 정수가 아닌 값이 있으면 지우지 않고 "양식에 없는 값" 으로 보이고, 고칠 때까지
     [일괄입력용] 을 만들지 않습니다(칸 이름을 알려 줍니다).
  4. 서식수변 — 점수 없이 조사불가 사유만 있어도 [일괄입력용] · [보고서 엑셀] 이 됩니다.
  5. 일괄입력용 파일 이름에 연도차수가 들어갑니다. 예: 방류하천_2025분기1차_곡교천1_어류_DB_v1.xlsx
     같은 지점의 다른 차수가 더는 같은 이름이 되지 않아, 여러 지점 일괄 출력도 하위 폴더 없이 한 폴더에 만듭니다.
  6. 어류·저서동물에서 개체수가 0 이거나 빈칸인 종은 일괄입력용에 나가지 않습니다(종전과 같음). 그런 종이 있으면
     내보내기 전에 "내보내지 않는 종 n건(종명…) — 계속할까요?" 를 묻습니다. 여러 지점 일괄 출력에서는 요약을 한 번만 묻습니다.
  7. 조류·포유류·양서파충류 — 행의 위도·경도가 둘 다 비어 있으면 조사개황 지점 좌표로 채워 일괄입력용·보고서 엑셀에 냅니다
     (관리자 자료에는 행 좌표만 들어가서, 목록 밖 지점에 지점 좌표만 적으면 좌표가 비었습니다). 화면 아래에 한 줄로 안내합니다.
  8. 수질 일괄입력용 — 측정하지 않은 항목의 등급 칸을 비웁니다(양식 수식이 빈칸을 0 으로 보아 대장균군 미측정이 "1a" 로 찍혔습니다).
  9. 조류 서식유형을 번호 1~6 으로 치거나 붙여넣으면 이름으로 바꿉니다
     (1 번식확실 · 2 번식추측 · 3 월동확실 · 4 채식 및 휴식 · 5 소리 · 6 이동). 대항목·세부의 번호는 그대로 둡니다(발주처 확인 대기).

■ 생태현황 지점 · 직접 입력
  · 대분류 [생태현황] 을 고르면 2025년까지의 조사 기록으로 만든 지점 149곳 가운데 지금 보고 있는 분류군의 지점만 보입니다
    (어류 118 · 조류 28 · 포유류 3). 양서파충류는 등록 지점이 없어 직접 입력만 됩니다.
    다른 분류군 탭으로 바꿔도 이미 고른 지점은 그대로 남고, "천안01 (조류 지점)" 처럼 표시됩니다.
  · 진위천1~5 · 오산천2 는 해마다 다른 곳이라 연도별로 나뉘어 있습니다. 조사연도를 먼저 넣으면 그 해 지점 하나만 보이고,
    연도를 넣기 전에는 "진위천1 [2023~2024]" 처럼 연도 구간이 함께 보입니다.
  · 좌표·하천명을 다시 확인해야 하는 지점은 지점 칸 아래에 "보완 필요: 좌표" 처럼 표시됩니다.
    조류·포유류 지점은 좌표가 비어 있으니 현장 좌표를 직접 적어 주세요. 발주처 검토 후 고쳐서 다시 배포합니다.
  · 목록에 없는 지점은 지점 칸에 이름을 직접 치고 Enter → "목록 밖 지점으로 입력됩니다" 에서 [예] 를 누른 뒤
    하천명·위도·경도를 적습니다. 대권역·중권역은 자동으로 안 채워지면 목록에서 고르거나 직접 적습니다.
    지점 칸 아래에 "목록 밖 지점" 이 표시됩니다.
  · 지점명이 없는 조사(예: 양서파충류)는 지점 칸을 비우고 하천명(대상지명)만 적어도 저장됩니다.
    자료함과 파일 이름에는 "용인산단(지점명 없음)" 처럼 나옵니다.
  · 방류하천은 지금처럼 목록에서만 고릅니다.

■ 확인 방법 (봐 주셨으면 하는 것)
  1. 국명 칸에 "방울하루살이" 를 한글로 쳤을 때 끊기지 않고 그대로 들어가는지
  2. 빠른추가에 ㅍㄹㅁ → 후보에서 고르고 개체수 → Enter. 같은 종을 한 번 더 넣으면 합쳐지는지
  3. 종을 하나 넣고 창을 닫으면 저장할지 묻는지([취소] 를 누르면 창이 남는지)
  4. 저장 완료 창의 [파일 열기] 로 엑셀이 바로 열리는지
  5. [새 지점] 으로 다음 지점을 입력할 때 6칸(대분류·연도차수·조사일·날씨·조사자·조사기관)이 압정을 꺼 둔 칸까지
     모두 남는지 / 압정을 켠 칸은 앱을 닫았다 다시 켜도 그 값이 채워지는지
  6. 조사개황·조사환경을 펼친 채 휠 — 그리드가 먼저, 끝에 닿으면 화면 전체가 내려가는지
  7. 선택 칸 목록을 열고 휠 — 목록만 움직이고 화면이 따라 내려가지 않는지
  8. 자료함에서 Ctrl 로 지점 두 개 → [보고서 일괄(한 파일)] · [일괄입력용 일괄]
  9. 자료함 [내보내기] 로 만든 zip 을 다른 PC 에서 [가져오기]
  10. 일괄입력용 엑셀을 관리자 앱 일괄등록에서 불러와 검수만(저장하지 않고) 해 보기
  11. 그리드 국명 칸에 "방울새"(또는 "돌고기") 를 치고 Enter — 그 이름 그대로 들어가는지
  12. 대분류 [생태현황] → 조사연도 2025 → 지점 "진위천1" 이 하나만 보이는지, 지점명 없이 하천명만 적고 저장되는지
  13. 한 지점에서 어류 탭 하천유형 "평지형", 서식수변 탭 하천유형 "지류" → 두 엑셀에 각각 나가는지
  14. 생태현황 지점 칸에 목록에 없는 이름을 치고 Enter → 확인 창 [예]/[아니요]
  15. 저서동물 조사환경에 Surber 30×30 3회를 넣고 → 건강성의 개체밀도가 "총 개체수 ÷ 0.27" 인지
      → [보고서 엑셀] 의 출현종 표에 개체밀도 열이 있는지. 드렛지/D-Net 횟수를 넣으면 "환산 불가" 로 바뀌는지
  [v0.3]
  16. 한 지점에 포유류를 넣고 [임시 저장] → [새 지점] → 같은 지점으로 서식수변만 넣고 [임시 저장]
      → [합치기] 를 고르면 자료함에서 그 지점을 열었을 때 포유류와 서식수변이 함께 있는지
  17. 어류에서 지점 "곡교천1" 을 고르면 하천차수 4 가 들어가는지 / 지점 "곡교천2" 에서 하천차수를 비운 채 종을 넣으면
      FAI 가 "-" 이고 "하천차수 필요" 가 보이며 [일괄입력용] 이 만들어지지 않는지
  18. [일괄입력용] 파일 이름에 연도차수가 들어가는지(예: 방류하천_2025분기1차_곡교천1_어류_DB_v1.xlsx)
  19. 어류 종 중 개체수를 0 이나 빈칸으로 둔 종이 있을 때 [일괄입력용] → "내보내지 않는 종 n건" 확인이 뜨는지
  20. 조류 행의 위도·경도를 비우고 [일괄입력용] → 그 행에 조사개황 지점 좌표가 들어가는지
  [v0.4]
  21. 같은 지점에 포유류(조사일 9월 6일)를 저장 → [새 지점] → 같은 지점 서식수변(조사개황 조사일 10월 1일) → [합치기]
      → 확인 창에 "포유류 조사일 2025-09-06 유지" 가 보이고, 포유류 일괄입력용 조사일이 20250906 · 서식수변이 20251001 인지
  22. 조류 지점 "원천리천8" 에서 하천명을 "황구지천" 으로 고치고 저장 → 다시 열어도 황구지천이고, 일괄입력용 하천이 황구지천인지
  23. 어류 DE 칸이나 하상 % 칸에 1.5 를 쳐 보기 → 받지 않고 "정수만 넣습니다" 가 보이는지
  24. 포유류 그리드에 흔적 칸이 "1.5" 인 줄을 엑셀에서 붙여넣기 → 그 칸만 비고 "정수가 아니라 넣지 않았습니다" 가 보이는지
  25. 저서동물 조사불가(건천화)로 [보고서 엑셀] → 건강성평가의 DI·H'·R1·J' 가 빈칸인지

■ 반영하지 않은 것과 이유
  · 하상 암반·콘크리트 칸 — 양식대로 8칸을 유지합니다(회신 내용).
  · 흐름상태 비율 입력 — 양식에 없어 여울/흐름/소 여러 개 고르기로만 했습니다. 필요하면 양식 개정이 먼저입니다.
  · 어류 채집 횟수 칸 — 일괄입력 양식에 칸이 없어 만들지 않았습니다. 어류는 채집도구와 채집소요시간(분)을 넣습니다.
    필요하면 양식에 칸을 먼저 추가해야 합니다. (저서동물은 양식대로 채집기마다 조사 횟수를 넣습니다)
  · 어류 일괄입력용 양식 통째 내장 — 최종본 어류 양식의 하천차수 수식이 앱의 엑셀 도구로 저장되지 않아,
    라벨·예시·필독 글자만 덧붙였습니다(값이 들어가는 칸은 종전과 같습니다).
  · 보고서 엑셀 칸 이름 중 표기만 조금 다른 것(예: "연도차수" ↔ 양식 "조사 연도/차수")은 그대로 두었습니다.
  · 양식 숫자 서식보다 자리가 많은 값은 관리자 프로그램이 그 서식대로 반올림해 읽습니다(예: pH 7.856 → 7.86).
    공식 양식으로 낸 자료와 같은 동작이라 막지 않았습니다.
  · 조류 도래유형 "길잃은새(Vag.)" — 2026-03 최종본 양식 선택지에 없어 넣지 않았습니다.
    예전 자료의 Vag. 는 지우지 않고 "양식에 없는 값" 으로 표시합니다.
