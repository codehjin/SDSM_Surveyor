하천 생태 모니터링 야장 (조사자앱) — 테스트본
==================================================

■ 실행 방법
  1. 이 폴더를 통째로 원하는 곳에 풀어 주세요.
     (압축을 푼 폴더 안에서 바로 실행해도 됩니다)
  2. SDSM_Surveyor_App.exe 를 두 번 누르면 실행됩니다.
  3. .NET 을 따로 설치하지 않아도 됩니다. 단독 실행형입니다.

  ※ 처음 실행할 때 Windows 가 "PC를 보호했습니다" 창을 띄울 수 있습니다.
     [추가 정보] → [실행] 을 누르면 됩니다. 서명되지 않은 사내 프로그램이라 그렇습니다.

■ 테스트본에 들어 있는 것
  · 자료함 예시 자료 3건
      - 방류하천 2025분기3차 곡교천4  … 7개 분류군 전부 입력된 예시
      - 방류하천 2025분기1차 오산천6  … 저서동물 · 어류 · 수질
      - 방류하천 2025분기4차 오산천6  … 조류 · 수질
    → 자료함이 비어 있을 때만 자동으로 들어갑니다.
      이미 쓰던 PC 라면 기존 자료를 건드리지 않습니다.

  · 지점 지도 29장
      - 곡교천 3장 (2026 기준 · St.11 포함 · 2022~2025 참고)
      - 오산천 23장 (2026 공통 + 분야별 연도 지점도)
      - 원천리천 3장 (2011 · 2022~2023 · 2024 이후)
    → 곡교천 2026 기준 지도와 오산천 2026 공통 지도는 좌표 보정이 되어 있어
      입력한 위·경도가 지도 위에 표시됩니다.

■ 봐 주셨으면 하는 것
  1. 지점명을 고르고 [지도] — 그림이 뜨고 표식이 제자리에 찍히는지
  2. 여러 지점을 이어서 입력할 때 압정(고정) 6칸이 유지되는지
     (조사자 · 조사기관 · 날씨 · 조사일 · 연도차수 · 대분류)
  3. [종목록] 팝업 — 담당 분류군 종을 찾아 넣고, 엑셀로 내려받기
  4. [행 삭제] — 행을 누르고 버튼, 또는 그리드에서 마우스 오른쪽 버튼
  5. 엑셀 저장 후 뜨는 "저장한 폴더를 열까요?" 창

■ 자료가 저장되는 곳
  C:\Users\<사용자>\AppData\Roaming\SDSM_Surveyor\
     sessions\  조사 자료(자료함)
     maps\      지점 지도 — 새 지도를 받으면 이 폴더의 파일을 바꾸면 됩니다
  프로그램 폴더를 지워도 위 자료는 남습니다.
