삼성 DS 모니터링 야장(조사자 앱) — 테스트본 v0.5.2
==================================================
  관리자 연계 시험 · 검토용 테스트본입니다. 화면 왼쪽 위 제목 옆에 v0.5.2 가 보이면 이 판입니다.
  예전 판에서 입력한 자료도 그대로 열립니다.

  ▶ 쓰는 법은 사용설명서에 있습니다 — 프로그램 폴더의 manual\surveyor_manual.pdf
    앱 위쪽 [사용설명서] 단추나 [정보] 창의 [사용설명서] 로도 엽니다(PDF 를 여는 프로그램이 있어야 합니다).
    이 파일에는 테스트할 때 필요한 것만 적었습니다.

■ 실행 방법
  1. 압축 파일(SDSM_Surveyor_테스트_v0.5.2_날짜.zip)을 원하는 곳에 풀어 주세요. SDSM_Surveyor_v0.5.2 폴더가 하나 생기고, 프로그램은 모두 그 안에 있습니다.
     (탐색기 [압축 풀기] · 압축 프로그램의 "여기에 풀기" 어느 쪽이든 같습니다)
  2. SDSM_Surveyor_v0.5.2 폴더 안의 SDSM_Surveyor_App.exe 를 두 번 누르면 실행됩니다.
  3. .NET 을 따로 설치하지 않아도 됩니다. 단독 실행형입니다.

  ※ 처음 실행할 때 Windows 가 "PC를 보호했습니다" 창을 띄울 수 있습니다.
     [추가 정보] → [실행] 을 누르면 됩니다. 서명되지 않은 사내 프로그램이라 그렇습니다.
  ※ 창이 하얗게만 보이고 글자가 나오지 않으면 — 프로그램 폴더(SDSM_Surveyor_App.exe 옆)에
     이름이 software_render 인 빈 파일(예: software_render.txt)을 만들고 다시 실행하세요.
     [정보] 창 「화면 그리기」 줄이 "소프트웨어(software_render 파일)" 로 바뀝니다. 파일을 지우면 원래대로 돌아갑니다.

■ 이번 판(v0.5.2)에서 바뀐 것
  1. 위쪽 [사용설명서] 단추 — 사용설명서 PDF 를 엽니다. [정보] 창에도 같은 단추가 있습니다.
  2. 알림 띠 — [임시 저장] · 붙여넣기 · [일괄입력용] 이 막혔을 때 등의 알림이 화면 아래 상태 바 바로 위에 한 줄로 보입니다.
     잘 됐다는 알림은 4초, 확인할 것이 있는 알림은 8초 뒤 사라지고 [×] 로 바로 닫을 수 있습니다.
  3. 어류 「조사불가 사유」 · 저서동물 「채집불가시(사유)」 — 접근불가 · 건천화 · 준설 · 공사중 가운데 하나를 고릅니다.
     고르면 등급이 '-' 가 됩니다. 덧붙일 말은 비고(저서는 특이사항)에 적습니다. 예전 자료의 다른 글은 지우지 않고 경고만 합니다.
  4. 어류 · 저서동물 그리드의 학명 칸은 고칠 수 없습니다(종목록 값).
  5. 그리드 개체수 칸 · 포유류 흔적 칸 · 양서파충류 관찰 칸에도 음수 · 글자가 들어가지 않습니다(저서 개체수는 소수 가능).
  6. 서식수변 점수 목록 아래 [비우기] — 고른 점수를 비웁니다(Delete · Backspace 도 됩니다).
  7. 위쪽 분류군 칩을 누르면 분류군마다 입력한 양이 보입니다.
  8. 보조 창(정보 · 자료함 · 확인 창 · 종목록 · 지도 · 지도 관리 · 동기화) 바탕을 메인 창과 같게 맞췄습니다.

■ 확인 방법 (봐 주셨으면 하는 것)
  1. 위쪽 [사용설명서] · [정보] 창 [사용설명서] 로 사용설명서가 열리는지
  2. [임시 저장] 뒤 상태 바 위에 「자료함에 저장되었습니다.」 알림 띠가 보였다가 사라지는지 / [×] 로 닫히는지
  3. 어류 조사불가 사유에서 '건천화' 를 고르면 FAI 등급이 '-' 인지
  4. 어류 그리드 개체수 칸에 -3 이나 1.5 를 치면 받지 않는지
  5. 빠른추가에 ㅍㄹㅁ → 후보에서 고르고 개체수 → Enter. 같은 종을 한 번 더 넣으면 합쳐지는지
  6. 종을 하나 넣고 창을 닫으면 저장할지 묻는지([취소] 를 누르면 창이 남는지)
  7. 같은 지점 · 같은 연도차수로 [새 지점] 뒤 다시 [임시 저장] → [합치기] · [바꾸기] · [취소] 가 뜨는지
  8. 저장 완료 창의 [파일 열기] 로 엑셀이 바로 열리는지
  9. 자료함에서 Ctrl 로 지점 두 개 → [보고서 일괄(한 파일)] · [일괄입력용 일괄]
  10. 자료함 [내보내기] 로 만든 zip 을 다른 PC 에서 [가져오기]
  11. 일괄입력용 엑셀을 관리자 앱 일괄등록에서 불러와 검수만(저장하지 않고) 해 보기
  12. 대분류 [생태현황] 지점 칸에 목록에 없는 이름을 치고 Enter → 확인 창 [예]/[아니요]
  13. 수질 BOD 칸에 "<0.5" 를 붙여넣기 → 받지 않고 "검출한계 미만은 칸을 비우고 비고(특이사항)에 ND 또는 <값을 적으세요" 가 보이는지

■ 반영하지 않은 것과 이유
  · 어류 하상 암반·콘크리트 칸 — 양식(지침 어류 조사표)대로 8칸을 유지합니다. 저서는 v0.4.1 부터 지침 6칸입니다.
  · 흐름상태 비율 입력 — 양식에 없어 여울/흐름/소 여러 개 고르기로만 했습니다. 필요하면 양식 개정이 먼저입니다.
  · 어류 채집 횟수 칸 — 일괄입력 양식에 칸이 없어 만들지 않았습니다. 어류는 채집도구와 채집소요시간(분)을 넣습니다.
    필요하면 양식에 칸을 먼저 추가해야 합니다. (저서동물은 양식대로 채집기마다 조사 횟수를 넣습니다)
  · 어류 일괄입력용 양식 통째 내장 — 최종본 어류 양식의 하천차수 수식이 앱의 엑셀 도구로 저장되지 않아,
    라벨·예시·필독 글자만 덧붙였습니다(값이 들어가는 칸은 종전과 같습니다).
  · 보고서 엑셀 칸 이름 중 표기만 조금 다른 것(예: "연도차수" ↔ 양식 "조사 연도/차수")은 그대로 두었습니다.
  · 양식 숫자 서식보다 자리가 많은 값은 관리자 프로그램이 그 서식대로 반올림해 읽습니다(예: pH 7.856 → 7.86).
    공식 양식으로 낸 자료와 같은 동작이라 막지 않았습니다.
  · 조류 도래유형 "길잃은새(Vag.)" — 2026-03 최종본 양식 선택지에 없어 넣지 않았습니다.
    예전 자료의 Vag. 는 지우지 않고 "양식에 없는 값" 으로 표시합니다.

■ 자료가 저장되는 곳
  C:\Users\<사용자>\AppData\Roaming\SDSM_Surveyor\
     sessions\  조사 자료(자료함) · 오류 기록(logs\) · 복구본(_recovery\)
     maps\      지점 지도 — 새 지도는 앱의 [지도 관리] 로 넣습니다
     settings.json  고른 분류군 · 압정 값 등
  프로그램 폴더를 지워도 위 자료는 남습니다. 새 판으로 바꿔도 그대로 열립니다.
  자세한 것은 사용설명서 1.3 · 1.4 · 부록 C.
